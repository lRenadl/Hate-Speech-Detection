# Hate Speech Detection in Social Media

A data science project that studies hate speech across three social media platforms: Reddit, Twitter and YouTube. The project covers the full data science pipeline, from collecting and labeling comments to cleaning, exploratory analysis, hypothesis testing and prediction.

## Project Phases

### Phase 1: Data Collection and Labeling

Comments and posts were collected from Reddit, Twitter and YouTube, then labeled.

- Notebooks: `Notebooks phase 1/` (`Reddit.ipynb`, `Twitter.ipynb`, `YouTube.ipynb`, `Graphs_2.ipynb`)
- Data: `datasets phase 1/`
- Report: `Hate_Speech_Project[11].docx`

### Phase 2: Processing and Exploratory Data Analysis

Each dataset was cleaned and standardized, explored separately, and then unified into one dataset.

- Notebooks: `Notebooks Phase2/` (processing and EDA for each platform, plus `Unify_datasets.ipynb`)
- Data: `Datasets Phase 2/` (cleaned and standardized versions of each dataset)
- Report: `Hate_Speech_Project_Phase2.docx`

### Phase 3: Hypothesis Testing and Prediction

Statistical hypotheses about hate speech were tested, and prediction models were trained to classify comments.

- Notebooks: `phase3/Notebooks/` (`Hypothesis Testing.ipynb`, `Prediction.ipynb`)
- Documents: `phase3/Documents/` (full report and logbooks)
- `phase3/Poster.png` and `phase3/Presentation.pdf`
